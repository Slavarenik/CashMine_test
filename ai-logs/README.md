# Project AI conversation logs

Session notes from work with Cursor agents on this project.

## Convention

- One file per day: `YYYY-MM-DD.md` (append if the day already exists).
- Optional topic files: `YYYY-MM-DD-<topic>.md` for long deep-dives.
- Keep entries short: decisions, pitfalls, commands that mattered — not full chat transcripts.

## For agents

1. At the start of a non-trivial task, skim the latest few `ai-logs/*.md` files.
2. At the end of a meaningful session (fixes, architecture, deploy, gotchas), append a short entry to today’s log.
3. Do not log secrets, tokens, or `.env` values.
