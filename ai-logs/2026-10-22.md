## Gotchas

- `sudo npm install` left `node_modules` owned by root → `EACCES` on later installs. Fix: `sudo chown -R "$(whoami)" node_modules package-lock.json` (and `~/.npm` if cache is broken). Never use `sudo npm` in the project again.
- Hooks: never put `useEffect` after early `return`s (loading/error) — causes “Rendered more hooks than during the previous render”.
- Web `/` 404 when there is no `index` route; home must be `index.tsx`, not only `home.tsx`.
- `npx expo start --web` may open browser but show a blank/404 if routing is wrong; check `http://localhost:8081/`.

## Firebase Hosting

- `firebase.json` → `"public": "dist"`.
- `firebase init` overwrote `dist/index.html` with the Firebase welcome page; deploy looked successful but URL showed the welcome screen.
- Fix: `npx expo export --platform web` then `firebase deploy --only hosting`. Do not re-init Firebase over `dist`.
- `app.json` web output is `"static"` (needed for Hosting).

## Deploy recipe

```bash
npx expo export --platform web
firebase deploy --only hosting
```
